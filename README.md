# ESS 배터리 수명 예측 — 초기 100사이클로 단수명 셀 조기 선별

ESS 배터리 교체 비용은 설치비(CAPEX)의 30\~40%를 차지함. 운전 초기 데이터만으로 **550사이클을 버티지 못할 셀(Short)을 미리 골라내** 교체 시점과 팩 구성을 계획하는 것이 목적임.
EDA 로 세운 모델 설계 전략을 그대로 구현하고, 배치가 바뀔 때 성능이 어떻게 달라지는지 해석함.


## 프로젝트 개요
- 데이터셋 : MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 데이터 : Batch 1 (2017-05-12)
- 평가 데이터 : Batch 2 (2018-02-20) / 추가 검증 : Batch 3 (2018-04-12)
- 태스크 : **Classification (장단수명 분류)** — cycle_life ≥ 550 → Long(1) / Short(0), 지표 F1-Score · Accuracy
- 모델링 방식 : log10(cycle_life) 회귀 → 예측 수명 550 기준 판정 (회귀는 분류를 위한 학습 수단, 이유는 [모델 선택](#모델-선택-및-근거) 참고)

## EDA
(보고서 원문 : [`docs/모델설계_보고서.pdf`](docs/모델설계_보고서.pdf), 코드 : `notebooks/01_EDA.ipynb`)

모델링은 EDA 로 수립한 모델 설계 전략을 그대로 구현했으며, 항목별 대응은 [아래 표](#모델-설계-전략--구현-대응)와 `notebooks/03_modeling.ipynb` 맨 앞·12절에 정리함

| 배치 | 셀 수 | 수명 중앙값 (범위) | Long / Short |
|---|---|---|---|
| B1 (학습) | 46 | 858 (534 \~ 1227) | 45 / 1 |
| B2 (테스트) | 39 | 472 (392 \~ 1186) | 9 / 30 |
| B3 (추가 검증) | 40 | 964 (541 \~ 1935) | 39 / 1 |

정제 : B2 수명 정답 없는 실험 셀 8개, B3 EOL 미도달 2셀·원논문 노이즈 채널 4셀 제외 / B1 중도 종료 10셀은 라벨 유지, 회귀 학습에서 제외

- **Cycle Life 분포**
	- B2 는 단수명(<500) 72%, B1·B3 는 0%. 장수명(>1000)은 B1 22%, B2 8%, B3 48%. B2·B3 는 오른쪽 꼬리(왜도 1.64·1.52)
	- 핵심 발견 : **학습 배치(B1)에 단수명 셀이 1개뿐** → 분류기를 직접 학습하면 경계를 배울 수 없음 → 수명 회귀 후 550 판정, log 변환

- **열화 곡선 분석**
	- 장·단수명 모두 "완만한 감소 → 급격히 꺾임 → 추락". 단수명 셀은 같은 모양을 더 빨리 겪음 (B2 단수명은 300\~400사이클에 꺾임)
	- Knee point 는 수명의 약 78% 시점, knee 와 수명의 상관 0.99 (세 배치 같은 직선)
	- 핵심 발견 : **초기 100사이클의 용량 "크기"는 모든 셀이 비슷** → 용량 대신 곡선 "모양" 변화를 봐야 함

- **ΔQ(V) 곡선 분석**
	- Cycle 100 − Cycle 10 방전 곡선 차이 : 단수명 셀이 2.8\~3.1V 에서 더 깊게 파임. 5−4 사이클 차이는 잡음 수준
	- ΔQ_100-10 분산(log)과 수명의 상관 : B1 −0.85 / B2 −0.72 / B3 −0.76, B2 Long/Short 분리력(AUC) 1.0
	- 핵심 발견 : **ΔQ_100-10 분산이 세 배치 공통의 핵심 신호** — 단, 100사이클은 관찰해야 함

- **충전 속도(C-rate)와 수명의 관계**
	- 충전 프로토콜별 평균 수명 : B1 23종 546 \~ 1226 (프로토콜에 따라 2배 차이) / B2 일반 셀 9종 394 \~ 484 / B3 8종 660 \~ 1588
	- B1 은 평균 충전 속도가 빠를수록 수명이 짧음(−0.63). B2·B3 는 모든 셀의 충전 시간이 같게 설계(4.8C)되어 충전 속도로 수명 설명 불가
	- 핵심 발견 : **충전 조건 피처는 배치가 바뀌면 관계가 뒤집힘** (충전 시간 +0.63 → −0.83) → 제외

- **추가 확인 : 상관관계·배치 간 관계 이동**
	- 후보 21개 중 14개는 배치 간 상관 방향이 일관되지 않음. ΔQ 분산·평균·최솟값은 서로 상관 0.97\~0.99 (VIF 200 이상)
	- B1 으로 그은 ΔQ–수명 직선은 B3 수명을 13% 오차로 맞히지만 B2 에서는 36% → **B2 일반 셀만 같은 ΔQ 에서 더 빨리 수명이 끝남**

## Modeling

### 피처 엔지니어링 전략
| 구분 | 피처 | 근거 |
|---|---|---|
| **최종** | `w100_dQ_logvar` (ΔQ_100-10 분산, log) | EDA : 세 배치 공통 강한 상관 / 모델링 : **B1 CV 수명 오차 최소** (7.7%) |
| 검토 후 미채택 | `w100_dQ_kurt` (첨도), `switch_soc` (2단계 전환 SOC) | 설계 규칙 "B1 CV 에서 개선될 때만 추가" → 개선 없음 (8.0%, 8.2%), 3개 함께 넣으면 한 fold 가 크게 불안정 |
| 제외 | ΔQ 평균·최솟값 | 핵심 피처와 같은 정보 (상관 0.97 이상) |
| 제외 | 충전 속도·충전 시간·1단계 전류·온도·저항 | 배치 간 관계가 뒤집힘 |
| 제외 | 5사이클 피처 | 잡음 수준 → 비교 기준선으로만 사용 |

- 처리 : 타깃 log10 변환 / 중도 종료 셀은 회귀 학습 제외 / 결측(B2 6셀 초기 내부저항 미측정)·표준화는 **B1 학습 데이터로만 fit** / 판정 기준 550 고정
- 피처 세트 선택은 **B1 학습 구간 GroupKFold CV 로만** 결정 (`results/feature_set_selection.csv`)

### 모델 선택 및 근거
- 후보 모델 : ElasticNet 회귀 → 550 / 단일 피처 선형회귀 → 550 (원논문 variance model) / 로지스틱 회귀 (class_weight balanced) / RandomForest 회귀 → 550 / 전부 Long (최저 기준선)
- 최종 모델 : **ElasticNet (log10 수명) → 550 판정**, 피처 `w100_dQ_logvar`, alpha 0.001 · l1_ratio 0.1 (B1 내부 GroupKFold 로 선택)
- 선택 이유 :
	1. **직선 관계** : ΔQ 분산과 log 수명이 세 배치 모두 직선 → 선형 모델로 충분
	2. **학습 범위 밖 예측** : B3 처럼 B1 범위 밖 값도 직선 연장으로 예측 (B3 오차 ElasticNet 11.9% vs RandomForest 15.8%)
	3. **소표본·다중공선성** : 학습 셀 36개 → 규제가 있는 단순 모델이 안전. 단, 최종 피처가 1개라 선택된 규제 강도는 격자 최솟값(사실상 규제 없음)이고 결과는 단일 선형회귀와 같음 → 규제는 보조 후보를 함께 검토하는 단계에서 계수를 안정시키는 안전장치 역할
	4. **해석 가능** : "ΔQ 분산 10배 → 예측 수명 0.67배" 로 운영자에게 설명 가능
	5. **B1 검증 기준 선택** : 로지스틱 회귀는 B2 정확도가 더 높지만(0.82) B1 CV 정확도 0.85 로 "전부 Long"(0.97)보다 낮고 1개 fold 는 학습 불가 → 테스트 결과로 모델을 바꾸지 않음 ([오류 분석](#오류-분석) 참고)
- 부스팅·딥러닝을 쓰지 않은 이유 : 학습 셀 36\~46개로 과적합 위험이 크고, 트리 계열은 학습 범위 밖을 예측하지 못함 (RandomForest 로 확인)

### 데이터 분할
- **Train (B1 CV)** : B1 학습 구간(35셀)에서 **충전 방식 단위 5-fold GroupKFold** 평균
- **Valid (B1 Hold-out)** : B1 충전 방식 5종(11셀)을 통째로 분리 — CV 가 아닌 Hold-out 을 쓰는 이유 : 각 셀이 서로 다른 충전 프로토콜로 실험되어 CV 를 쓰면 같은 프로토콜 셀이 학습·검증에 나뉘어 누수 위험, Hold-out 은 셀 단위 분리를 명확히 보장
- **Test** : B1 전체로 다시 학습한 모델로 B2(필수), B3(추가) 평가

### Gap 해석
- **Train − Valid ≈ 0** : 과적합 없음. Valid 수명 오차 11.1% 로 CV 7.7% 와 비슷
- **Valid − Test(B2) = +0.56** : EDA 에서 예고한 배치 간 관계 이동. 그러나 **B2 AUC 1.0** — 예측 수명의 순서는 완벽하고 **절대 수명을 과대 예측해 550 선을 넘긴 것**이 원인
- **Target − Test = +0.52** : 원논문(95.1%)은 5사이클 입력이며 학습셋과 1차 테스트셋을 같은 실험 배치들에서 나눈 조건 (이번 과제는 배치를 통째로 나눈 B1 단독 학습). 같은 5사이클 입력으로 B1 단독 학습하면 B2 정확도 0.21·AUC 0.29 로 더 나쁨 → 100사이클 입력을 택한 설계 결정이 타당
- **B3** : 수명 오차 11.9% 로 B1 Hold-out(11.1%)과 비슷 → B1 에서 배운 관계가 다른 배치(B3)에서는 유지됨 (설계 단계 예상과 일치)
- **누수 점검** : B1 데이터만으로 고른 피처 세트는 B1 CV 에서도 오차가 큼(10.2% vs 7.7%) → 최종 피처 선택은 테스트 배치 정보 없이도 같은 결론


## 오류 분석
- **모델이 가장 크게 틀린 셀의 공통점**
	- B2 오분류 22셀이 **모두 B2 일반 셀(newstructure 아님)** — 일반 셀 정확도 0.27, newstructure 셀 1.00
	- 일반 셀은 수명을 평균 1.32배 과대 예측 (최대 실제 393 → 예측 722), newstructure 셀은 1.08배로 B1·B3 와 비슷
	- 특정 충전 방식에 몰리지 않음 → 충전 조건이 아닌 셀 lot·실험 조건 차이
	- B3 오분류는 유일한 Short 셀 1개(541 → 611 예측). 단 B3 안에서 가장 짧게 예측된 셀로 순서는 맞음
- **원인 가설 및 개선 방향**
	- 가설 : B2 일반 셀은 같은 ΔQ 변화에서 열화가 더 빨리 진행되는 다른 lot (실험 시기 약 9개월 차이, 장비 조건 차이)
	- 개선 ① **소량 라벨 재보정** (운영 시나리오, 본 성능과 분리) : B2 셀 k개의 실제 수명으로 판정 기준만 이동

		| 라벨 수 k | 0 | 3 | 5 | 10 |
		|---|---|---|---|---|
		| B2 나머지 셀 Accuracy | 0.436 | 0.898 | 0.919 | 0.932 |
		| B2 나머지 셀 macro-F1 | 0.436 | 0.885 | 0.906 | 0.916 |

	- 개선 ② 셀 구조·lot·실험 조건을 메타 피처로 수집 (현재는 newstructure 표시만 있음)
	- 개선 ③ 단수명 사례가 포함된 여러 lot 로 학습 (B1 의 단수명은 1개뿐)
	- 참고 : 로지스틱 회귀는 단수명 1개에 45배 가중치를 줘 경계를 보수적으로(ΔQ 분산 −3.57) 잡아 B2 에서 유리했으나, B1 에서는 Long 5셀을 Short 로 오판 → 경계가 표본 1개에 좌우되어 불안정. "B2 에는 더 보수적인 기준이 맞았다" 는 점은 재보정의 필요성을 뒷받침함


## ESS 도메인 해석
- **이 모델을 실제 BESS 에 적용한다면**
	- 설치 후 약 100사이클(수개월 운전) 시점에 셀·모듈별 ΔQ 분산을 계산 → **교체·점검 우선순위** 결정 (순위 지표 AUC 1.0 → 같은 lot 안의 상대 비교에 강함)
	- 단수명으로 판정된 모듈은 피크 대응 부하 배분을 줄이고 교체 예산을 앞당겨 편성 (교체 비용 = CAPEX 30\~40%)
	- 새 lot 도입 시 셀 3\~10개를 가속 수명 시험해 판정 기준을 재보정 → 정확도 0.44 → 0.90\~0.93
- **한계와 실 배포를 위해 필요한 것**
	- lot·조건이 바뀌면 절대 수명 기준이 어긋남 (B2) → 재보정 절차가 운영 프로세스에 포함되어야 함
	- 학습 데이터의 단수명 셀이 1개 → 단수명 사례 확보 필요
	- 실험실 조건(고정 온도·정전류 방전)과 실제 운전(부분 충방전·온도 변동)이 다름 → 현장 데이터로 ΔQ 계산 방식 검증 필요
	- 판정에 100사이클 필요 → 제조 직후 스크리닝이 아닌 **운전 초기 진단** 용도
